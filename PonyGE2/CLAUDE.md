# LLM Wiki — Thesis Research Knowledge Base

You maintain a persistent, compounding markdown wiki for this thesis project. The wiki sits between immutable raw sources and the user. You write and maintain the wiki; the user curates sources, asks questions, and directs analysis.

**Domain:** Grammatical Evolution (PonyGE2) searches hierarchical aggregation structures over Vodafone-style telecom switch/CDR data; Matrix Profile (STUMPY) scores candidate series as a label-free discord detector; ROC-AUC on synthetically injected anomalies (μ±3σ, 168h windows) is the fitness function.

**Research gap:** No reviewed work integrates all four — structure search + Matrix Profile + telecom operational data + AUC-based evaluation.

- Source pages: `author-year-short-title` or `article-N-slug` when author is ambiguous.

## Operations

### Ingest

Trigger: user says "ingest article N", "process source X", or drops a new file into raw collection.

**Workflow:**

1. Read the raw source (`Literature Review Articles/N.md` and optional PDF).
2. Optionally discuss key takeaways with the user before writing.
3. Create or update `wiki essay/sources/<slug>.md` using the source template.
4. Create or update relevant `wiki essay/concepts/` and `wiki essay/entities/` pages (typically 2–5 per source).
5. Add `[[wikilinks]]` bidirectionally where appropriate.
6. Update `wiki essay/index.md` — add or revise the entry under the correct category.
7. Append one entry to `wiki essay/log.md`.
8. If the source contradicts an existing wiki claim, note the contradiction on both pages.

**Ingest order:** Work through articles 1–28 in `Literature Review Articles/` one at a time unless the user requests batch ingest.

**Merge rules:**

- González et al. (2024) + García González et al. (2022) — cite 2024 as primary; 2022 for S-VAE comparator only.
- Yeh et al. (2017) + Yeh et al. (2016) — prefer 2017 for method detail; 2016 for MP I speedup link.

**Writing rules for ingested content:**

1. Prioritise application and reported results over method theory.
2. If no accessible numeric result exists, say so explicitly — do not invent.
3. Do not treat synthetic-injection AUC as directly comparable to expert-label range-F1 without qualification.
4. Respect include decisions: Core, Supporting, Optional, Ch. 2 mainly.

### Query

Trigger: user asks a question about the thesis domain or literature.

**Workflow:**

1. Read `wiki essay/index.md` to locate relevant pages.
2. Read those pages (and raw sources only if wiki coverage is insufficient).
3. Synthesise an answer with citations to wiki pages and/or raw sources.
4. If the answer is substantial and reusable, offer to file it as `wiki essay/synthesis/<slug>.md` and update the index.
5. Append a `query` entry to `wiki essay/log.md`.

### Lint

Trigger: user says "lint the wiki" or periodically after several ingests.

**Check for:**

- Contradictions between pages (especially numeric claims)
- Stale claims superseded by newer ingests
- Orphan pages with no inbound `[[wikilinks]]`
- Important concepts mentioned but lacking a concept page
- Missing cross-references between related sources
- `wiki essay/index.md` out of sync with actual pages
- Articles in raw collection not yet ingested (track 1–28 progress)

**Output:** Report findings to the user; fix clear issues; append a `lint` entry to `wiki essay/log.md`.

## Index and log

### `wiki essay/index.md`

Content-oriented catalog. Organise by category:

- Overview
- Sources (by literature section)
- Concepts
- Entities
- Synthesis

Each entry: `[[wikilink]]` — one-line summary — optional metadata (year, include tier, source count).

Update on every ingest, significant query filing, or lint fix.

### `wiki essay/log.md`

Append-only. Never edit or delete past entries.

**Format:**

```markdown
## [2026-06-26] ingest | González 2024 — One Model to Find Them All
Created wiki essay/sources/gonzalez-2024-one-model.md; updated concepts/telecom-anomaly-detection, entities/telco-dataset.
```

**Prefixes:** `ingest`, `query`, `lint`, `setup`, `synthesis`

Parseable with: `grep "^## \[" wiki essay/log.md | tail -5`
