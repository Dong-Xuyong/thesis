## 1. Motivation

In Telecom Networks, is produced a huge volume of network information KPIs, and expert anomaly labels is scarce. So candidate aggregation is  ranked by standard supervised metrics on real incidents. This thesis focuses on injecting synthetic anomalies into each candidate series and using AUC-ROC on Matrix Profile discord scores as a label line fitness signal.

Unexpected changes in ordinary traffic patterns or behaviors can occur at any instant, potentially resulting in any of the aforementioned issues. Identify abnormal events in the system as soon as possible. In this context, detecting anomalies in time series is a relevant task. Nonetheless, a simple sequence usually does not represent telecom data. Traffic can be viewed under several categories. A call can have different types, for instance. Likewise, an event type may possess many different values. Likewise, a specific subscriber may belong to a specific type. Traffic type, service type, partner-related information, and other categories would create a myriad of different ways to analyze the data.

Having a fully aggregated view can hide local anomalies, while monitoring every categorical combination separately exposes them only at high computational and interpretability cost. This creates a dilemma: which aggregation level should anomaly detection work on? A set hierarchy might be used, or rules can be manually set. For example, if we have access to the user department or protocol type, then we can detect anomalies in there. When examining certain combinations of categorical variable values, some anomalies become visible. For example, designating user protocols. Perhaps we should run anomaly detection independently on each variable combination. Nonetheless, this may be very costly computationally and in terms of interpretability. Therefore, we must develop automatic searching methods. Moreover, it must identify abnormal behavior anywhere in the network. In addition, a disparity between a "normal" network trace and an "anomalous" one, as measured with a (weighted) Hamming distance, should tend to be larger for nodes that are "closer" to the location of the anomaly in topology or corresponding to broken or compromised components.

## 2. Objectives and Expected Results

A new framework for detecting anomalies in grouped telecommunications time series with hierarchical aggregation has been developed through Grammatical Evolution (an evolutionary algorithm that evolves executable computer programs). The telecommunications sector has experienced rapid growth in data. Consequently, the implementation of algorithms capable of detecting anomalies has become important. Detecting anomalies in telecommunications is useful for identifying patterns. Our aim, from a data perspective, is to work with the different categorical dimensions that represent mobile network traffic records. Records are characterized by multiple dimensions that capture call type, event type, subscriber type, traffic type, service type, partner-related information, and more. With all these dimensions, it is also possible to construct multiple levels of aggregation so that an anomaly can be studied at the global and local levels.

The aim of this thesis, from a methodological point of view, is to design a grammar-based evolutionary approach that automatically generates candidate hierarchical structures to be evaluated by how well they aid anomaly detection in the resulting time series. The evaluation aims to assess the quality of the evolved hierarchy using synthetic anomalies and performance measures such as ROC-AUC. To put it differently, artificial anomalies can facilitate an evaluation since anomaly labels are nonexistent. This assessment allows us to compare various aggregation techniques and evaluate the effectiveness of partial hierarchies in improving performance.
